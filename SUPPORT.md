# Support

- **Docs first**: `docs/` — per-platform onboarding (Google/Meta/TikTok), hosting, automation, deliverability, capabilities map.
- **Health check**: `node apps/mcp/bin/socials-mcp.js doctor` diagnoses most setup problems.
- **Questions / usage**: open a [GitHub Discussion] or an issue with the `question` template.
- **Bugs**: issue template `bug` — include doctor output (secrets auto-redacted) and the failing tool's JSON result.
- **Security**: see SECURITY.md — do not use public issues for vulnerabilities.

Response happens best-effort; this is a community project — PRs welcome (see CONTRIBUTING.md).
