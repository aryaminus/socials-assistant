# Engagement benchmarks (read when comparing rates)

Use these as context, not verdicts. Platform benchmarks drift by year and region; the user's own trendline beats any external number.

## Engagement rate (ER = (likes+comments+shares)/views)

| Tier | Typical range | Read |
|---|---|---|
| Nano (1–10k followers) | 4–10% | Strong above ~8% on TikTok |
| Micro (10–100k) | 3–8% | Strong above ~6% |
| Mid (100k–1M) | 2–6% | Volume compensates |

- TikTok tends highest; Instagram reels mid; YouTube videos lowest ER but longest watch.
- A falling ER with rising views usually means the algorithm reached beyond the core audience — not necessarily bad; check retention if available.

## Posting cadence

- Consistency beats frequency: regular weekly slots outperform burst-then-silence.
- Gaps >2× the usual cadence show up in follower-growth dips within ~10 days.

## Follower growth

- Healthy nano/micro organic: 0.5–3%/week of follower base. Spikes = viral content; check whether the spike retained (followers gained vs lost next 7 days).

## Watch time / retention (when Studio CSVs are imported)

- Hook survives if ≥60–70% retained at 3 seconds.
- Mid-video drop >30% between consecutive buckets signals a pacing problem, not a hook problem.
- Average watch time rising while views fall = content deepening for a narrower audience.

## Using benchmarks honestly

- Always compare against the user's own trailing 4-week average first.
- State the window for every number quoted in digests and pitches ("last 30 days").
- When a benchmark and the vault disagree, trust the vault and say so.
