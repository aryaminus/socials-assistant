# Rate card guidance (nano/micro creators)

Indicative 2026 ranges for creators with roughly 1k–100k followers. Adjust by market, niche premium (finance/tech pay more), and exclusivity. The user always sets final rates — these anchor the conversation, never override them.

## Per-deliverable starting ranges

| Deliverable | Typical range | Notes |
|---|---|---|
| TikTok video | $50–300 | Up to $800 for exceptional fit/performance |
| Instagram reel | $75–400 | Story add-on +$25–75 |
| IG story set (3) | $50–200 | |
| YouTube integration (60–90s) | $100–500 | Scales with channel size |
| YouTube dedicated video | $300–1,500 | Micro tier |
| Bundle (TikTok + reel) | sum −20–30% | Push bundles in pitches |

## Usage rights & add-ons (quote separately, never free)

- Paid amplification / spark ads usage: +30–100% of base
- Whitelisting (running ads from the creator's handle): +50% and time-limited
- Exclusivity (no competitor for N weeks): +20–50% per month of exclusivity
- Rush delivery (<7 days): +25%

## Negotiation floors

- New brands: 50% upfront, balance on delivery.
- Never cut price below floor — cut scope instead (1 platform instead of 2, 30-day usage instead of 90).
- First-time collaborators: usage limited to organic; paid usage is a renewal conversation.
- Product-only deals: accept only if the product's value ≥ the cash floor AND the user genuinely wants it.

## Pricing the pitch

Use `socials-mcp:media_kit_data`: price on 30-day verified views and ER, not follower count. If 30-day views are missing, say so and price conservatively rather than inflating.
